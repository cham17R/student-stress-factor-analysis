# Student Stress Factor Analysis

## Project Overview
This project explores factors associated with student stress using survey-based exploratory data analysis (EDA).

The analysis was conducted using Python, pandas, matplotlib, and Jupyter Notebook.

---

## Objectives
- Explore relationships between stress and optimism
- Analyze the effect of sleep duration on stress
- Examine how social support relates to student stress
- Compare multiple behavioral and lifestyle factors

---

## Tools Used
- Python
- pandas
- matplotlib
- Jupyter Notebook

---

## Key Findings
- Lower sleep duration was associated with higher stress levels
- Lower social support levels showed higher stress trends
- Optimism showed weak correlation with stress within the sample
- Very poor work-life balance was linked to higher stress
